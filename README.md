## Getting Started

Follow these steps to access the repository on your local computer.

### 1. Clone the Repository

```bash
git clone https://github.com/hasinidudyala-sketch/MERN-Class-DEMO-Hasini-Dudyala.git
```

### 2. Navigate to the Project Folder

```bash
cd MERN-Class-DEMO-Hasini-Dudyala
```

### 3. Open in Visual Studio Code

```bash
code .
```

### 4. Install Dependencies

For Node.js-based projects, open the required project folder in the terminal and install its dependencies:

```bash
npm install
```

Run this command only in folders containing a `package.json` file.

For Python-based projects, install the dependencies specified by their respective requirements files, if available.

### 5. Run the Project

The execution steps depend on the individual project.

For example, a React project may use:

```bash
npm run dev
```

A Node.js project may use:

```bash
npm start
```

Refer to the individual project files and configuration for the correct commands.
